# blindoptics-rs

Rust port of `blindoptics.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `BlindDiffuse` (`blindoptics.c:10`)
- `BlindBeam` (`blindoptics.c:15`)
- `BlindBeamBeam` (`blindoptics.c:20`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports the Venetian blind optics: `BlindOpticsDiffuse` (diffuse solar or visible,
and IR, properties of the blind from its slats) and `BlindOpticsBeam` (beam properties at a
profile angle) from `src/EnergyPlus/WindowManager.cc`, and `MaterialBlind::BeamBeamTrans` from
`src/EnergyPlus/Material.cc`. It uses `view_fac`, `invert_matrix` and `diffuse_average` from
`glazing-rs` (a path dependency). `CalcWindowBlindProperties`, which loops these over slat and
profile angles and stores the tables in the blind material, is not ported yet.

The oracle (`rust/oracles/blindoptics/`) sets up one `Material::MaterialBlind` (slat width,
separation, thickness) and passes the slat properties as plain numbers. Where the exchange matrix
is singular, `InvertMatrix` stops with a fatal error the shim does not catch; those generated
extreme inputs are recorded as crashes, and the port returns NaN for them.
