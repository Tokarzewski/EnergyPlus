# sumhat-rs

Rust port of `sumhat.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `SumHAT` (`sumhat.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports `ZoneTempPredictorCorrector::SpaceHeatBalanceData::calcSumHAT` from
`src/EnergyPlus/ZoneTempPredictorCorrector.cc` for one heat transfer surface. The zone air heat
balance runs it for every space on every predict and correct step; a space's sums add up its
surfaces in turn.

For a window, the convective gains to the zone air come first:

- the divider's gain behind an interior shade or blind (the shade then covers the divider area
  too);
- the equivalent layer gain;
- the convection in the gap between the glass and an interior shade or blind;
- an airflow window's gains. In a zone with no heat to return air, its return gain is also
  booked into the window heat gain and its report variables.

Then come the frame and divider convection, then the surface's own convection. The total goes
into the sum its reference air temperature asks for: the zone mean air, the adjacent air, or the
supply air of a controlled zone (the mean air before the system has flow). Every sum starts at 0
and adds in the C++ order.

The oracle (`rust/oracles/sumhat/`) sets up one zone, one space and one surface, then calls the
real `calcSumHAT`. These return NaN in both (ADR-009):

- flags outside 0 or 1;
- shading flags and reference temperatures outside their enums;
- the supply air reference in a zone that is not controlled, which EnergyPlus stops on as a
  fatal error.

## Accepted gate exceptions (2026-11-23)

- **Size:** `rust-anything gate` fails only its size check: about 230 lines of Rust against a
  limit set by the 6-line C forwarder in `rust/oracles/sumhat/`. Waived under ADR-007.
- **Recording, diff and gate:** 12932 cases in all: 1250 surfaces, each asked for all ten results,
  plus rust-anything's generated cases. WSL kept going down and cutting long driver runs, so the
  cases were recorded and diffed in chunks of 1500 with the crate's own driver
  (`.rust-anything/driver_c.py record` and `diff`). All 12932/12932 match. The gate was run on a
  copy of this crate with the first 4000 cases: every check passes (behaviour 4000/4000) except
  size.
- **Speed:** 2.86x faster: 10 ns per call against 27 ns for the C++. The C++ figure includes the
  oracle writing about 25 state fields before each call. Timed by a direct in-process loop over
  the recorded cases, both sides called through a C function pointer, best of 15 interleaved
  runs.
