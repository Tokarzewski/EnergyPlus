# tstat-rs

Rust port of `tstat.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `TstatSetPoints` (`tstat.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports `ZoneTempPredictorCorrector::CalcZoneAirTempSetPoints` from
`src/EnergyPlus/ZoneTempPredictorCorrector.cc` for one thermostat. EnergyPlus runs it for every
controlled zone at every zone time step:

- the zone set points of each control type: uncontrolled, single heating (when used), single
  cooling, single heating and cooling, and dual set point, with the thermostat's high and low
  set points;
- the operative temperature adjustment (`AdjustAirSetPointsforOpTempCntrl`), constant or
  scheduled radiative fraction;
- the temperature and humidity overcooling of the cooling set point
  (`AdjustCoolingSetPointforTempAndHumidityControl`), constant or scheduled range;
- the EMS heating and cooling overrides (`OverrideAirSetPointsforEMSCntrl`).

The oracle (`rust/oracles/tstat/`) sets up one zone with one thermostat on constant schedules,
then calls the real `CalcZoneAirTempSetPoints`. These return NaN in both (ADR-009): `which`
outside 0 to 5, `ctype` outside 0 to 4 (EnergyPlus reports an illegal control type, which needs
the error file), `opctrl` or `ovctrl` outside 0 to 2, and a flag outside 0 or 1.

Not ported yet: adaptive comfort set points, optimum start, faulty thermostat offsets, thermal
comfort control (`CalcZoneAirComfortSetPoints`), and the loop over several thermostats.

## Accepted gate exceptions (2026-11-23)

- **Size:** `rust-anything gate` fails only its size check: 227 lines of Rust (with tests) against
  a limit set by the 6-line C forwarder in `rust/oracles/tstat/`. Waived under ADR-007.
- **Recording, diff and gate:** 13611 cases in all: 2200 thermostats, each asked for all six
  results, plus rust-anything's generated cases. WSL kept going down and cutting long driver
  runs, so the cases were recorded and diffed in chunks of 1500 with the crate's own driver
  (`.rust-anything/driver_c.py record` and `diff`). All 13611/13611 match. The gate was run on a
  copy of this crate with the first 4000 cases: every check passes (behaviour 4000/4000) except
  size.
- **Speed:** 2.96x faster: 13 ns per call against 40 ns for the C++, whose call also sets the
  thermostat up. Timed by a direct in-process loop over the recorded cases, both sides called
  through a C function pointer, best of 15 interleaved runs.
