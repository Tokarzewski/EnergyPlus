Rust port of `glazing.c`, bridged with the C ABI. Generated by rust-anything.

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports the glazing optics and small solvers of `src/EnergyPlus/WindowManager.cc`:
`TransAndReflAtPhi` (the Fresnel angular dependence, its clear and bronze glass fallbacks, and the
simple glazing system's 28-cell curve selection), `W5LsqFit`, `DiffuseAverage`, `ViewFac` (blind
slat view factors), `InvertMatrix` with `LUdecomposition` and `LUsolution`, and `Interpolate`. It
uses `InterpolateBetweenTwoValues` and `InterpolateBetweenFourValues` from `leaf-rs` (a path
dependency). The window heat balance itself (`SolveForWindowTemperatures` and the gas and shade
flow routines) reads construction and surface state and is not ported yet.

The oracle (`rust/oracles/glazing/`) takes plain numbers: `GlassFit` evaluates the glass at the
ten incidence angles as `W5InitGlassParameters` does before fitting, and `MatInverse` builds a
matrix from four parameters. A singular matrix (the C++'s fatal error), and a NaN SHGC or U-factor
with the simple glazing model (which would reach the C++'s `assert(false)`), return NaN in both
(ADR-009).

## Accepted gate exceptions (2026-11-22)

- **Size:** `rust-anything gate` fails only its size check: about 580 lines in `src/port.rs`
  against a limit set by the 26-line C forwarder in `rust/oracles/glazing/`. Waived under ADR-007.
- **Speed:** `TransAndReflAtPhi` ties with the C++ (0.95x); the others are 1.2x to 3.5x faster.
