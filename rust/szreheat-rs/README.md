# szreheat-rs

Rust port of `szreheat.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `SZReheat` (`szreheat.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports `SetPointManager::SPMSingleZoneReheat::calculate` from
`src/EnergyPlus/SetPointManager.cc`, which EnergyPlus runs for every
SetpointManager:SingleZone:Reheat (most single zone air systems) at every HVAC iteration:

- the supply air temperature with no heating or cooling: the mixed air at the minimum outdoor air
  fraction from the return and outdoor air (or the loop inlet temperature without a mixer), plus
  the fan's temperature rise when the manager names the fan's nodes;
- the supply temperature that meets the zone load at the zone inlet flow, in the dead band only
  when the unconditioned supply would push the zone past a set point, otherwise the load or the
  load to the nearer set point, whichever the unconditioned supply cannot meet;
- the result limited to the manager's minimum and maximum (`psychrometrics-rs`, unit 1, for the
  mixed temperature and the specific heat).

The oracle (`rust/oracles/szreheat/`) sets up the control zone's demand, the air loop's outdoor
air fraction and seven nodes, then calls the real routine. These return NaN in both (ADR-009): any
input that is not finite or lies outside what EnergyPlus meets (see the shim).

Not ported yet: the other set point managers and the node set point updates.

## Accepted gate exceptions (2026-11-23)

- **Size:** `rust-anything gate` fails only its size check: 174 lines of Rust (with tests) against
  a limit set by the 6-line C forwarder in `rust/oracles/szreheat/`. Waived under ADR-007.
- **Recording, diff and gate:** 13866 cases in all: 13500 real-world cases plus rust-anything's
  generated ones. WSL kept going down and cutting long driver runs, so the cases were recorded and
  diffed in chunks of 1500 with the crate's own driver (`.rust-anything/driver_c.py record` and
  `diff`). All 13866/13866 match. The gate was run on a copy of this crate with the first 4000
  cases: every check passes (behaviour 4000/4000) except size.
- **Speed:** slightly faster than the C++, 1.15x: 37 ns per call against 43 ns. Timed by a direct
  in-process loop over the recorded cases, both sides called through a C function pointer, best of
  15 interleaved runs.
