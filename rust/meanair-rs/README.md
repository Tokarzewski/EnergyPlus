# meanair-rs

Rust port of `meanair.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `MeanAirTemps` (`meanair.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports `HeatBalanceAirManager::calcMeanAirTemps` from
`src/EnergyPlus/HeatBalanceAirManager.cc` for one zone's air report variables. EnergyPlus runs it
for every zone and space at every zone time step:

- the mean air temperature and humidity ratio, the operative temperature and the dew point;
- the thermostat's operative temperature with its radiative fraction, when the model has
  operative temperature control, the zone is controlled and its thermostat uses it (constant or
  scheduled fraction);
- the wet bulb globe temperature, when it is reported.

The psychrometric functions come from `psychrometrics-rs` (a path dependency). The wet bulb and
saturation temperature lookups there keep the C++ caches; without them this port ran at 0.10x.

The oracle (`rust/oracles/meanair/`) sets up one controlled zone with a thermostat, then calls the
real `calcMeanAirTemps` on zone 1's report variables, reset to their defaults first. These return
NaN in both (ADR-009): `which` outside 0 to 5, `opctrl` outside 0 to 2, a flag outside 0 or 1,
and the fatal errors EnergyPlus stops on.

Not ported yet: the loop over zones and spaces in `ReportAirHeatBalance` that calls it.

## Accepted gate exceptions (2026-11-23)

- **Size:** `rust-anything gate` fails only its size check: 121 lines of Rust (with tests) against
  a limit set by the 6-line C forwarder in `rust/oracles/meanair/`. Waived under ADR-007.
- **Recording, diff and gate:** 12884 cases in all: 2100 zone states, each asked for all six
  results, plus rust-anything's generated cases. WSL kept going down and cutting long driver runs,
  so the cases were recorded and diffed in chunks with the crate's own driver
  (`.rust-anything/driver_c.py record` and `diff`). All 12884/12884 match. The gate was run on a
  copy of this crate with the first 4000 cases: every check passes (behaviour 4000/4000) except
  size.
- **Speed:** 1.99x faster: 24 ns per call against 47 ns for the C++, whose call also sets the zone
  and thermostat up. Timed by a direct in-process loop over the recorded cases, both sides called
  through a C function pointer, best of 15 interleaved runs.
