# wingas-rs

Rust port of `wingas.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `GapCon` (`wingas.c:10`)
- `GapProps` (`wingas.c:15`)
- `GapNusselt` (`wingas.c:20`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports the window gap gas routines of `src/EnergyPlus/WindowManager.cc`:
`WindowGasConductance` (single gases and ISO 15099 mixtures, with the Prandtl and Grashof
numbers), `WindowGasPropertiesAtTemp` and `NusseltNumber` (the gap Nusselt number for windows
heated from above or below, above and below 60 degrees of tilt). The two gas routines group the
same mixing formulae differently, and the port keeps each grouping.

The oracle (`rust/oracles/wingas/`) sets up gap 0 from EnergyPlus's built-in `Material::gases`
(air, argon, krypton, xenon) and surface 1's height. A mixture of no gases (the C++'s
`assert(false)`) returns NaN in both (ADR-009); where `NusseltNumber` leaves its result unset
(a NaN tilt with the window heated from below), both return the oracle's starting value, -1.

## Accepted gate exceptions (2026-11-22)

- **Size:** `rust-anything gate` fails only its size check: about 270 lines in `src/port.rs`
  against a limit set by the 16-line C forwarder in `rust/oracles/wingas/`. Waived under ADR-007.
- **Speed:** `NusseltNumber` ties with the C++ (1.08x; its time is in `pow`); the gas routines
  are 1.2x to 1.4x faster.
