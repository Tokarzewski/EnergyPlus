# outsurf-rs

Rust port of `outsurf.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `OutsideSurfTemp` (`outsurf.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports `HeatBalanceSurfaceManager::CalcOutsideSurfTemp` from
`src/EnergyPlus/HeatBalanceSurfaceManager.cc` for one exterior surface. The outside surface heat
balance runs it for every exterior surface on every heat balance iteration:

- the boundary temperatures: the sky temperature and outdoor dry bulb, replaced by a surrounding
  surfaces property's sky and ground temperature schedules and its surrounding surface
  temperature, and by the ground surfaces' average temperature;
- the outside face temperature from the heat balance case the surface falls in: slow or quick
  conduction (first cross CTF term up to or above 0.01), with or without exterior movable
  insulation, an other side conditions model, or an embedded source or sink;
- the outside thermal radiation report, and the radiant system heat balance coefficients of a
  surface with a source or sink.

The oracle (`rust/oracles/outsurf/`) sets up one exterior wall in one space, then calls the real
function. These return NaN in both (ADR-009): flags outside 0 or 1, and exterior movable
insulation on a construction with a source or sink, which EnergyPlus reports as an error
(`ErrorFlag`) and stops on.

Not ported yet: tubular daylighting device domes.

## Accepted gate exceptions (2026-11-23)

- **Size:** `rust-anything gate` fails only its size check: about 290 lines of Rust against a
  limit set by the 6-line C forwarder in `rust/oracles/outsurf/`. Waived under ADR-007.
- **Recording, diff and gate:** 13035 cases in all: 2500 surfaces, each asked for all five
  results, plus rust-anything's generated cases. WSL kept going down and cutting long driver
  runs, so the cases were recorded and diffed in chunks of 1500 with the crate's own driver
  (`.rust-anything/driver_c.py record` and `diff`). All 13035/13035 match. The gate was run on a
  copy of this crate with the first 4000 cases: every check passes (behaviour 4000/4000) except
  size.
- **Speed:** 3.00x faster: 15 ns per call against 45 ns for the C++. The C++ figure includes the
  oracle writing about 35 state fields before each call. Timed by a direct in-process loop over
  the recorded cases, both sides called through a C function pointer, best of 15 interleaved
  runs.
