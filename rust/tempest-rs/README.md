# tempest-rs

Rust port of `tempest.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `Tempest` (`tempest.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports `SetPointManager::SPMTempest::calculate` from
`src/EnergyPlus/SetPointManager.cc`, which EnergyPlus runs for every SetpointManager:Warmest and
:Coldest (the supply air reset of most VAV and dual duct systems) at every HVAC iteration:

- warmest: the lowest supply temperature any cooled zone needs to meet its cooling load at its
  terminal's maximum flow, starting from the manager's maximum;
- coldest: the highest any heated zone needs for its heating load (the cooled zones when the loop
  heats none), starting from the manager's minimum;
- the result limited to the manager's range, and held at the maximum (warmest) or minimum
  (coldest) when the zones' total cooling or heating load is below 1 W (`psychrometrics-rs`, unit
  1, for the specific heat).

The oracle (`rust/oracles/tempest/`) sets up an air loop of one to four zones with their nodes and
loads, then calls the real routine. These return NaN in both (ADR-009): any input that is not
finite or lies outside what EnergyPlus meets (see the shim).

Not ported yet: separate heating inlet nodes (dual duct heating decks), the warmest temperature
and flow manager, and the node updates.

## Accepted gate exceptions (2026-11-23)

- **Size:** `rust-anything gate` fails only its size check: 159 lines of Rust (with tests) against
  a limit set by the 6-line C forwarder in `rust/oracles/tempest/`. Waived under ADR-007.
- **Recording, diff and gate:** 13885 cases in all: 13500 real-world cases plus rust-anything's
  generated ones. WSL kept going down and cutting long driver runs, so the cases were recorded and
  diffed in chunks of 1500 with the crate's own driver (`.rust-anything/driver_c.py record` and
  `diff`). All 13885/13885 match. The gate was run on a copy of this crate with the first 4000
  cases: every check passes (behaviour 4000/4000) except size.
- **Speed:** slightly faster than the C++, 1.16x: 62 ns per call against 72 ns, on a loaded
  machine. Timed by a direct in-process loop over the recorded cases, both sides called through a
  C function pointer, best of 15 interleaved runs.
