# xmix-rs

Rust port of `xmix.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `CrossMixing` (`xmix.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports the cross mixing part of `ZoneEquipmentManager::CalcAirFlowSimple` from
`src/EnergyPlus/ZoneEquipmentManager.cc` for one `ZoneCrossMixing` object, which exchanges equal
air flows between a zone and its source zone. EnergyPlus runs it at every system time step:

- the minimum and maximum zone, source zone and outdoor temperature limit schedules;
- the delta temperature test (positive or zero, as a value or a schedule; negative stops the
  exchange), with the air density and specific heat at the two zones' average conditions;
- both zones' mixing sums (`MCPM`, `MCPTM`, `MixingMassFlowZone`, `MixingMassFlowXHumRat`) and
  the object's report flag.

The psychrometric functions come from `psychrometrics-rs` (a path dependency).

The oracle (`rust/oracles/xmix/`) sets up two zones with simple air flows and only this cross
mixing object, then calls the real `CalcAirFlowSimple`. These return NaN in both (ADR-009):
`which` outside 0 to 8, a flag outside 0 or 1, a pair of minimum and maximum schedules with the
minimum above the maximum (EnergyPlus warns and changes it, which needs the error file), and the
fatal error EnergyPlus stops on, a negative air density.

Not ported yet: CO2 and generic contaminant mixing, space heat balance (space volume shares),
refrigeration door mixing, and the warning path for crossing limit schedules.

## Accepted gate exceptions (2026-11-23)

- **Size:** `rust-anything gate` fails only its size check: 215 lines of Rust (with tests) against
  a limit set by the 6-line C forwarder in `rust/oracles/xmix/`. Waived under ADR-007.
- **Recording, diff and gate:** 13935 cases in all: 1500 zone pairs, each asked for all nine
  results, plus rust-anything's generated cases. WSL kept going down and cutting long driver runs,
  so the cases were recorded and diffed in chunks of 1500 with the crate's own driver
  (`.rust-anything/driver_c.py record` and `diff`). All 13935/13935 match. The gate was run on a
  copy of this crate with the first 4000 cases: every check passes (behaviour 4000/4000) except
  size.
- **Speed:** 1.85x faster: 31 ns per call against 57 ns for the C++, whose call also resets both
  zones' air flow sums. Timed by a direct in-process loop over the recorded cases, both sides
  called through a C function pointer, best of 15 interleaved runs.
