# shadowmulti-rs

Rust port of `shadowmulti.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `ShadowMulti` (`shadowmulti.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports one receiving surface shaded by one to three shadowing surfaces, as
`src/EnergyPlus/SolarShading.cc` computes it: `SHADOW` (the shadow projections and the receiving
figure) and `SHDGSS` over the shadowing heat transfer surfaces, each one facing away from the sun
brought into the receiving plane (`CTRANS`), cut at it (`CLIP`), projected, snapped onto the
receiving vertices and overlapped in place on the receiving figure; `MULTOL`, which overlaps each
new shadow on the shadows kept before it so that overlapping shadows count once; the sunlit area
summed over every figure kept; and `SHADOW`'s clamp to [0, net area]. `DeterminePolygonOverlap`
works on a figure table, as the C++ does, so the in-place and `MULTOL` overlaps read and write the
same figures. The clipping is Sutherland-Hodgman or SlaterBarsky, from units 28 and 29.

`SHDGSS` keeps its sun threshold as `int const sunIsUp = DataEnvironment::SunIsUpValue;`, so the
0.00001 truncates to 0 and a caster with any sun on it (cosine above 0) casts nothing. The port
keeps that; the recorded cases include casters at cosine 0.00001.

The oracle (`rust/oracles/shadowmulti/`) gives the real `SHADOW` a sunlit base surface 1 and up
to three heat transfer surfaces as its general shadowing surfaces, each with its own sun cosine
and schedule minimum, with no back surfaces or subsurfaces. `MaxHCS` is 8, the most figures three
casters can need, so `TooManyFigures` cannot arise. These return NaN in both (ADR-009): an `algo`
outside 0 or 1; a caster count outside 1 to 3; vertex counts other than 3 or 4; vertices or origin
past 30 m; local axis, sun or cosine values past 1; schedule values outside [0, 1] or an area
outside [0, 1e6]; and a sun so low over the receiving plane that a projection passes 4, which keeps
every projected coordinate within 1000 m, where the homogeneous products fit in `Int64`.

## Accepted gate exceptions (2026-11-22)

- **Size:** `rust-anything gate` fails only its size check: about 970 lines in `src/port.rs`
  against a limit set by the 6-line C forwarder in `rust/oracles/shadowmulti/`. Waived under ADR-007.
- **Speed:** 1.28x faster: 806 ns per call against 1030 ns for the C++ (both include the
  oracle's setup). The figure table (17 figures) is zeroed and figures are copied for each
  overlap, which is where the port could gain next.
  Timed by a direct in-process loop over the recorded cases, both sides called through a C
  function pointer, best of 15 interleaved runs: `rust-anything bench` ran past an hour while
  other sessions loaded the same WSL. The same loop gives 1.76x for unit 29 and 0.83x for
  unit 28, against 1.84x and 0.89x from `rust-anything bench`.
