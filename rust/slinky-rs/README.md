## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## Accepted gate exceptions (2026-11-22)

- **Size:** `rust-anything gate` fails only its size check: 252 code lines in `src/port.rs`
  against a limit of 173, which comes from the 41-line C forwarder in `rust/oracles/slinky/`,
  not from the roughly 370 lines of real code in `src/EnergyPlus/GroundHeatExchangers/Slinky.cc`.
  Accepted as is by the owner.
- **erfc:** `erfc` comes from the `libm` crate (MIT, 0.2.16), as stable Rust has none. It rounds
  differently from glibc's in some cases, and the response functions subtract two `erfc` terms,
  so 23 of the 708 recorded cases differ by 1 to 32 ulp (at most 6e-15 relative). They are listed
  in `known-diffs.jsonl`; 2 of them are g-function cases, and the other 66 recorded g-functions
  match bit for bit. Accepted by the owner.
