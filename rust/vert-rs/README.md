## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports the long-time-step g-function code of `GLHEVert` in
`src/EnergyPlus/GroundHeatExchangers/Vertical.cc`: `distances`, `calcResponse`, `integral`,
`doubleIntegral`, `setupTimeVectors` and `calcUniformHeatFluxGFunctions`, with the borehole points
placed as `GLHEResponseFactors::SetupBHPointsForResponseFactorsObject` places them, plus
`frictionFactor`, `calcPipeConductionResistance` and `getAnnualTimeConstant`. Not ported yet: the
short-time-step finite-volume g-functions, the resistances that read the plant loop's fluid
properties, and the GHEDesigner path. The oracle's fields are up to 3 by 3 boreholes; a time
vector longer than 1000 values (or one that never ends, for a zero or negative time scale) returns
NaN or 0 (ADR-009).

## Accepted gate exceptions (2026-11-22)

- **Size:** `rust-anything gate` fails only its size check: about 280 lines in `src/port.rs`
  against a limit set by the 51-line C forwarder in `rust/oracles/vert/`, not by the roughly 200
  lines of real code ported. Waived under ADR-007.
- **erfc:** `erfc` comes from the `libm` crate (MIT, 0.2.16), as for slinky-rs (ADR-006). It rounds
  differently from glibc's in places, so 21 of the 3118 recorded cases (2 of them g-functions)
  differ, by at most 3.4e-16 relative on realistic inputs; two generated extremes (results near
  1e-17 and 1e-284) differ by up to 1.1e-10 relative. They are listed in `known-diffs.jsonl`.
