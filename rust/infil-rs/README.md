# infil-rs

Rust port of `infil.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `Infiltration` (`infil.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports the infiltration part of `ZoneEquipmentManager::CalcAirFlowSimple` from
`src/EnergyPlus/ZoneEquipmentManager.cc` for one zone with up to two infiltration objects.
EnergyPlus runs it for every zone at every system time step:

- the design flow rate model (`ZoneInfiltration:DesignFlowRate`, with its constant, temperature,
  velocity and velocity squared terms), the Sherman-Grimsrud model
  (`ZoneInfiltration:EffectiveLeakageArea`) and the AIM-2 model
  (`ZoneInfiltration:FlowCoefficient`);
- the outdoor, standard and indoor density bases, the zone's outdoor air node, the first system
  time step's lagged zone air, and EMS flow overrides;
- the zone's infiltration sums (`MCPI`, `OAMFL`, `MCPTI`).

The psychrometric functions come from `psychrometrics-rs` (a path dependency).

The oracle (`rust/oracles/infil/`) sets up one zone with simple air flows and only infiltration,
then calls the real `CalcAirFlowSimple`. These return NaN in both (ADR-009): `which` outside 0 to
8, the object count outside 0 to 2, a model or density basis outside its enum, a flag outside 0 or
1, and the fatal error EnergyPlus stops on, a negative air density.

Not ported yet: the rest of `CalcAirFlowSimple` (ventilation, mixing, cross mixing, refrigeration
door mixing, zone air balance), space heat balance, zone air mass flow balance adjustments.

## Accepted gate exceptions (2026-11-23)

- **Size:** `rust-anything gate` fails only its size check: 364 lines of Rust (with tests) against
  a limit set by the 6-line C forwarder in `rust/oracles/infil/`. Waived under ADR-007.
- **Recording, diff and gate:** 14143 cases in all: 1500 zones, each asked for all nine results,
  plus rust-anything's generated cases. WSL kept going down and cutting long driver runs, so the
  cases were recorded and diffed in chunks of 1500 with the crate's own driver
  (`.rust-anything/driver_c.py record` and `diff`). All 14143/14143 match. The gate was run on a
  copy of this crate with the first 4000 cases: every check passes (behaviour 4000/4000) except
  size.
- **Speed:** 2.17x faster: 40 ns per call against 87 ns for the C++, whose call also resets the
  zone's other air flow sums. Timed by a direct in-process loop over the recorded cases, both
  sides called through a C function pointer, best of 15 interleaved runs.
