# intrad-rs

Rust port of `intrad.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `IRView` (`intrad.c:10`)
- `IRScriptF` (`intrad.c:15`)
- `IRFmrt` (`intrad.c:20`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports the view factor and exchange arithmetic of
`src/EnergyPlus/HeatBalanceIntRadExchange.cc`: `CalcApproximateViewFactors`, `FixViewFactors`
(with its reciprocity, row-scaling and iteration-limit branches), `CalcScriptF` with
`CalcMatrixInverse`, `CalcFMRT` and `CalcFp`. Not ported: `InitInteriorRadExchange` and
`CalcInteriorRadExchange`, which read and write the enclosures, surfaces and the module's state,
and the user-entered view factor input routines.

The oracle (`rust/oracles/intrad/`) builds a box zone from a bit mask (floor, roof, four walls,
an internal mass) with the zone's dimensions, rotation and emissivities, and returns one element
of a matrix or one of `FixViewFactors`' check values. Where `FixViewFactors` stops with a fatal
error, and for a mask or index outside the zone, both return NaN (ADR-009).

## Accepted gate exceptions (2026-11-22)

- **Size:** `rust-anything gate` fails only its size check: about 470 lines in `src/port.rs`
  against a limit set by the 16-line C forwarder in `rust/oracles/intrad/`. Waived under ADR-007.
