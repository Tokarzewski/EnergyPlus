# perezsky-rs

Rust port of `perezsky.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `PerezSky` (`perezsky.c:9`)
- `ClipLine` (`perezsky.c:14`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports two routines of `src/EnergyPlus/SolarShading.cc`: `AnisoSkyViewFactors`, the
Perez anisotropic sky model (isotropic, circumsolar and horizon/zenith parts of the sky diffuse
multiplier, with both the simple and the detailed sky diffuse branches), and `CLIPLINE`, the
Liang-Barsky line clipper. The rest of `SolarShading.cc` (the polygon shadow engine, interior
solar distribution, window shading control) is not ported yet.

The oracle (`rust/oracles/perezsky/`) sets up one exterior surface (outward normal, tilt, sky view
factor, shading ratios, sunlit fraction) and the sun and weather, and returns one of the stored
results by `which`. Where `AnisoSkyViewFactors` stops with a fatal error (a beam incidence cosine
more than 0.0001 outside [-1, 1]), both return NaN (ADR-009).

## Accepted gate exceptions (2026-11-22)

- **Size:** `rust-anything gate` fails only its size check: about 230 lines in `src/port.rs`
  against a limit set by the 11-line C forwarder in `rust/oracles/perezsky/`. Waived under ADR-007.
