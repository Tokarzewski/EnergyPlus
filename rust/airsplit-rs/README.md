# airsplit-rs

Rust port of `airsplit.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `AirSplit` (`airsplit.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports what `SplitterComponent::SimAirLoopSplitter` runs for a zone splitter, from
`src/EnergyPlus/SplitterComponent.cc`: `InitAirLoopSplitter`, `CalcAirLoopSplitter` and
`UpdateSplitter`. EnergyPlus runs them twice per air loop pass for every AirLoopHVAC:ZoneSplitter
(before and after the zone equipment), many times per HVAC iteration:

- on the first call: on the first HVAC iteration the inlet flow and maximum available flow shared
  equally among the outlets, every outlet shut when no flow is available at the inlet, and the
  inlet's temperature, humidity ratio, enthalpy and pressure passed to every outlet;
- on the second call: the outlets' flows and available flows summed back onto the inlet, with
  whether the inlet flow changed by more than 0.01 kg/s.

The oracle (`rust/oracles/airsplit/`) sets up one splitter on five nodes, then runs the three
routines. These return NaN in both (ADR-009): any input that is not finite or lies outside what
EnergyPlus meets (see the shim).

Not ported yet: the inlet node reset at the beginning of an environment, the contaminant copies,
the node quality copy, and the plenum and return path splitters.

## Accepted gate exceptions (2026-11-23)

- **Size:** `rust-anything gate` fails only its size check: 195 lines of Rust (with tests) against
  a limit set by the 6-line C forwarder in `rust/oracles/airsplit/`. Waived under ADR-007.
- **Recording, diff and gate:** 13980 cases in all: 420 splitters, each asked for all 32 results,
  plus rust-anything's generated cases. WSL kept going down and cutting long driver runs, so the
  cases were recorded and diffed in chunks of 1500 with the crate's own driver
  (`.rust-anything/driver_c.py record` and `diff`). All 13980/13980 match. The gate was run on a
  copy of this crate with the first 4000 cases: every check passes (behaviour 4000/4000) except
  size.
- **Speed:** faster than the C++, 3.86x: 71 ns per call against 273 ns. Most of the C++ side's
  time is the oracle resetting five full node records per call; the routines themselves are a
  few copies and sums. Timed by a direct in-process loop over the recorded cases, both sides
  called through a C function pointer, best of 15 interleaved runs.
