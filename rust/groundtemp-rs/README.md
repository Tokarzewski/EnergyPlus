# groundtemp-rs

Rust port of `groundtemp.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `GTKusudaSeconds` (`groundtemp.c:12`)
- `GTKusudaMonth` (`groundtemp.c:17`)
- `GTXingSeconds` (`groundtemp.c:22`)
- `GTXingMonth` (`groundtemp.c:27`)
- `GTSite` (`groundtemp.c:32`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports the undisturbed ground temperature models in
`src/EnergyPlus/GroundTemperatureModeling/`: Kusuda-Achenbach and Xing (`getGroundTemp`,
`getGroundTempAtTimeInSeconds`, `getGroundTempAtTimeInMonths`), and the four monthly site tables
(deep, shallow, building surface, F/C factor), which share one body of code. Not ported: the
models' input factories (they read input objects) and the finite difference model.

`remainder` (IEEE 754, an exact operation) comes from the `libm` crate. The oracle
(`rust/oracles/groundtemp/`) builds each model from plain numbers; a site table is
`t0, t0 + dt, ..., t0 + 11 dt`. Where the C++ indexes outside a site table (months 0, -1, 12k
after its `month % 12` fold) or converts an out-of-range double to `int`, and for Kusuda's month
`INT_MIN` (`_month - 1` overflows), both return NaN (ADR-009).

## Accepted gate exceptions (2026-11-22)

- **Size:** `rust-anything gate` fails only its size check: about 150 lines in `src/port.rs`
  against a limit set by the 26-line C forwarder in `rust/oracles/groundtemp/`. Waived under
