# mixedsp-rs

Rust port of `mixedsp.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `MixedSP` (`mixedsp.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports `SetPointManager::SPMMixedAir::calculate` from
`src/EnergyPlus/SetPointManager.cc`, which EnergyPlus runs for every SetpointManager:MixedAir (the
mixed air, coil outlet and fan inlet set points of nearly every air loop) at every HVAC iteration:

- the reference node's set point less the supply fan's temperature rise;
- with the cooling coil's nodes named, the freeze check when the coil is cooling and it is colder
  outdoors than the coil's minimum outlet temperature: the set point raised so the coil outlet
  stays at that minimum, for blow through (the reference node at the coil outlet temperature),
  draw through and coil outlet reference layouts.

The oracle (`rust/oracles/mixedsp/`) sets up the five nodes and the outdoor temperature, then calls
the real routine with its missing set point check already done. These return NaN in both
(ADR-009): any temperature that is not finite or lies outside -60 to 80 C.

Not ported yet: the missing reference set point check (a severe error, or an EMS lookup) and the
node set point updates.

## Accepted gate exceptions (2026-11-23)

- **Size:** `rust-anything gate` fails only its size check: 99 lines of Rust (with tests) against a
  limit set by the 6-line C forwarder in `rust/oracles/mixedsp/`. Waived under ADR-007.
- **Recording, diff and gate:** 13788 cases in all: 6750 managers, each asked for both results,
  plus rust-anything's generated cases. WSL kept going down and cutting long driver runs, so the
  cases were recorded and diffed in chunks of 1500 with the crate's own driver
  (`.rust-anything/driver_c.py record` and `diff`). All 13788/13788 match. The gate was run on a
  copy of this crate with the first 4000 cases: every check passes (behaviour 4000/4000) except
  size.
- **Speed:** faster than the C++, 1.83x: 12 ns per call against 21 ns, a few nanoseconds of which
  are the oracle's per-call node setup. Timed by a direct in-process loop over the recorded cases,
  both sides called through a C function pointer, best of 15 interleaved runs.
