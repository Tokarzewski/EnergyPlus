# twowaypipe-rs

Rust port of `twowaypipe.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `TwoWayPipe` (`twowaypipe.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```
## What is ported

`src/port.rs` ports `ManageTwoWayCommonPipe` from `src/EnergyPlus/HVACInterfaceManager.cc` with a
constant speed primary pump: the flows in a two-way common pipe (primary to secondary, and the
recirculation on each leg) and the inlet temperatures of both sides, iterated eight times when the
supply side's inlet set point leads and four times when the demand side's does.

The variable speed primary pump branch (which calls `SetActuatedBranchFlowRate` on the supply
inlet branch) is not ported. The oracle (`rust/oracles/twowaypipe/`) calls the real routine on one
plant loop, after the common pipes have been set up and outside the first environment call, and
returns one result at a time. These return NaN in both (ADR-009): any input that is not finite or
lies outside what EnergyPlus meets (see the shim).

## Gate (2026-11-23)

- **Gate:** `rust-anything gate` passes every check but size (165 lines of Rust for the 6-line C
  forwarder, which hides the C++ routine). Waived under ADR-007.
- **Recording, diff and gate:** 13829 cases in all: 13500 real ones (2250 calls asked for all six
  results) and rust-anything's generated cases, recorded and diffed in chunks with the crate's own
  driver, from fresh chunk folders. All 13829/13829 match. The gate was run on a copy of this crate
  with the first 4000 cases: behaviour 4000/4000.
- **Speed:** 1.10x (36 ns per call against 39 ns). The C++ side's time includes the shim setting
  six node fields and the common pipe before each call. Timed by a direct in-process loop over the
  recorded cases, both sides called through a C function pointer, best of 15 interleaved runs.
