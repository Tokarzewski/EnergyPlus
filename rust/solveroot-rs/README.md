# solveroot-rs

Rust port of `solveroot.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `SolveRootX` (`solveroot.c:13`)
- `SolveRootFlag` (`solveroot.c:18`)
- `SolveRoot2Algo` (`solveroot.c:23`)
- `SolveRoot2X` (`solveroot.c:28`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`solve_root` and `solve_root2` in `src/port.rs` are the ports of `General::SolveRoot` (all six
`RootAlgo` methods and the `default` branch) and `General::SolveRoot2` (the algorithm-picking
stats) from `src/EnergyPlus/General.cc`. They take any closure, so ported units call them
directly. The four exports run them on the oracle's test functions (a cubic, an exponential, a
sine and a constant, `test_fn`) and exist only for recording; inputs where the C++ counters would
overflow, or SolveRoot2 would index its stats at -1, return NaN or 0 (ADR-009).

## Accepted gate exceptions (2026-11-22)

- **Size:** `rust-anything gate` fails only its size check: about 290 lines in `src/port.rs`
  against a limit set by the 21-line C forwarder in `rust/oracles/solveroot/`, not by the roughly
  220 lines of `SolveRoot` and `SolveRoot2` in `General.cc` plus the oracle's test functions.
  Waived under ADR-007.
