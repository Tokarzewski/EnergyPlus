# plantiface-rs

Rust port of `plantiface.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `PlantIface` (`plantiface.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports `UpdatePlantLoopInterface` from `src/EnergyPlus/HVACInterfaceManager.cc` for a
loop without a common pipe, which every plant and condenser loop runs after simulating each half:

- the other side's inlet enthalpy from its old temperature and the water specific heat;
- its new temperature from the half-loop tank (`UpdateHalfLoopInletTemp`, `halfloop-rs`, unit 84,
  whose `half_loop` and `water_cp` are now public);
- the flow difference (against the smaller of 0.001 kg/s and 1 percent of the larger flow) and
  the temperature difference (against 0.01 K) pushed onto the side's convergence histories, which
  are rotated with the oldest entry moved to the front and then overwritten;
- the not-converged flags and the out-of-tolerance flag (flow and temperature on the demand side,
  flow only on the supply side), and the outlet's flows, quality and pressure (unless the loop has
  pressure components) passed across.

`std::min` and `std::max` are written out as the C++ library does them. The oracle
(`rust/oracles/plantiface/`) calls the real routine on one water loop, with every slot of the
convergence histories set to one value, and returns one result at a time. These return NaN in
both (ADR-009): any input that is not finite or lies outside what EnergyPlus meets (see the shim).

## Gate (2026-11-23)

- **Gate:** `rust-anything gate` passes every check but size (126 lines of Rust for the 6-line C
  forwarder, which hides the routine and its inputs). Waived under ADR-007.
- **Recording, diff and gate:** 13864 cases in all: 13500 real ones (964 calls asked for all
  fourteen results, plus 4) and rust-anything's generated cases, recorded and diffed in chunks with
  the crate's own driver, from fresh chunk folders. All 13864/13864 match. The gate was run on a
  copy of this crate with the first 4000 cases: behaviour 4000/4000.
- **Speed:** 1.65x (61 ns per call against 100 ns), part of it the shim resetting a node and
  filling four history arrays before each C++ call. Timed by a direct in-process loop over the
  recorded cases, both sides called through a C function pointer, best of 15 interleaved runs.
