## What is ported

`src/port.rs` ports seven routines of `src/EnergyPlus/WeatherManager.cc`: `CalcSkyEmissivity`
(Clark and Allen, Brunt, Idso, Berdahl and Martin), `ASHRAETauModel` (2009 and 2013/2017
coefficients), `CalculateDailySolarCoeffs`, `CalculateSunDirectionCosines`, `DetermineSunUpDown`,
`WaterMainsTempFromCorrelation` and `DayltgLuminousEfficacy`. It uses `PsyPsatFnTemp` from
`psychrometrics-rs` and `AirMass` from `weather-rs` (path dependencies).

The oracle (`rust/oracles/solarpos/`) sets the site (latitude, longitude, time zone meridian),
the clock and the day's solar variables per call and returns one of a routine's results by
`which`. A month outside 1 to 12 for the luminous efficacy returns NaN in both (ADR-009).

## Accepted gate exceptions (2026-11-22)

- **Size:** `rust-anything gate` fails only its size check: about 350 lines in `src/port.rs`
  against a limit set by the 36-line C forwarder in `rust/oracles/solarpos/`. Waived under ADR-007.
- **Speed:** overall a tie with the C++ (1.00x). `CalcSkyEmissivity` ran at 0.5x while `psychrometrics-rs` computed each
  saturation pressure again; with the same cache as the C++ (2026-11-23) it runs at 1.07x
  (16 ns per call against 17 ns). The other five are 1.1x to 1.5x faster.
