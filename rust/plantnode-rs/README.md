## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports five node helpers from `src/EnergyPlus/PlantUtilities.cc` that plant components
call when they initialise, pass flow through or bound a flow:

- `InitComponentNodes`: the component's flow limits, floored at zero, set on the inlet, the flows
  reset;
- `SafeCopyPlantNode`: the inlet's state copied to the outlet, the available flows narrowed to the
  hard limits, the pressure passed through only on a loop without pressure simulation;
- `BoundValueToNodeMinMaxAvail`, `BoundValueToWithinTwoValues`: a flow bounded below, then above;
- `TightenNodeMinMaxAvails`: the available flows narrowed by new limits that lie inside them.

`min` and `max` are ObjexxFCL's (`a < b ? a : b`, `a < b ? b : a`), which give a different signed
zero from Rust's `f64::min`/`max`; the recorded cases include signed zeros. The oracle
(`rust/oracles/plantnode/`) calls the real routines and returns one result at a time. These return
NaN in both (ADR-009): any input that is not finite or lies outside what EnergyPlus meets (see the
shim).

## Gate (2026-11-23)

- **Gate:** `rust-anything gate` passes every check but size (139 lines of Rust for the 26-line C
  forwarder). Waived under ADR-007.
- **Recording, diff and gate:** 14749 cases in all: 13500 real ones (the five routines interleaved,
  plus signed-zero cases) and rust-anything's generated cases, recorded and diffed in chunks with
  the crate's own driver, from fresh chunk folders. All 14749/14749 match. The gate was run on a
  copy of this crate with the first 4000 cases (all five routines): behaviour 4000/4000.
- **Speed:** `BoundTwo`, the one pure function, is level (1.07x, 4 ns against 5 ns). The others
  read like large gains (`InitNodes` 23.1x, `BoundNode` 10.6x, `Tighten` 7.8x, `SafeCopy` 5.9x) but
  are not comparable: the C++ side's time includes the shim resetting whole nodes before each call,
  and the routines themselves are a few assignments. Timed by a direct in-process loop over the
  recorded cases, both sides called through a C function pointer, best of 15 interleaved runs.
