# zonehist-rs

Rust port of `zonehist.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `ZoneHistory` (`zonehist.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports the zone air history updates of `src/EnergyPlus/ZoneTempPredictorCorrector.cc`
for a fully mixed zone (not a space). The zone air heat balance runs them for every zone on every
zone or system time step, and when the system time step is shortened:

- `ZoneSpaceHeatBalanceData::pushZoneTimestepHistory`: shift the zone time step temperature and
  humidity ratio histories and take in the averages, the new humidity ratio and relative humidity,
  and, for the analytical and Euler solutions, the previous values;
- `ZoneSpaceHeatBalanceData::pushSystemTimestepHistory`: the same for the down-stepped system
  time step histories;
- `ZoneSpaceHeatBalanceData::revertZoneTimestepHistory`: shift the zone time step histories back;
- both forms of `DownInterpolate4HistoryValues` (five values, and the four-value array form with
  its return value): history values on a time step 2, 3, or 4 or more times shorter.

The relative humidity comes from `psychrometrics-rs` (a path dependency).

The oracle (`rust/oracles/zonehist/`) sets up one zone, then calls the real functions; `op` picks
which. These return NaN in both (ADR-009): `which` outside 0 to 29, `op` outside 0 to 4 and
algorithms outside their enum.

Not ported yet: spaces, and the displacement ventilation, underfloor air distribution and
RoomAirflowNetwork histories.

## Accepted gate exceptions (2026-11-23)

- **Size:** `rust-anything gate` fails only its size check: about 250 lines of Rust against a
  limit set by the 6-line C forwarder in `rust/oracles/zonehist/`. Waived under ADR-007.
- **Recording, diff and gate:** 13110 cases in all: 420 zone states, each asked for all thirty
  values, plus rust-anything's generated cases. WSL kept going down and cutting long driver runs,
  so the cases were recorded and diffed in chunks of 1500 with the crate's own driver
  (`.rust-anything/driver_c.py record` and `diff`). All 13110/13110 match. The gate was run on a
  copy of this crate with the first 4000 cases (its `psychrometrics-rs` path made absolute):
  every check passes (behaviour 4000/4000) except size.
- **Speed:** 0.93x, slightly slower: 30 ns per call against 28 ns for the C++, even though the
  C++ figure includes the oracle's per-call setup. The updates are mostly copies, so taking in the
  35 arguments and building the state dominates on both sides; returning the one value asked for
  instead of building the output arrays changed nothing measurable. Timed by a direct in-process
  loop over the recorded cases, both sides called through a C function pointer, best of 15
  interleaved runs.
