# zonesums-rs

Rust port of `zonesums.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `ZoneSums` (`zonesums.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports `ZoneSpaceHeatBalanceData::calcZoneOrSpaceSums` from
`src/EnergyPlus/ZoneTempPredictorCorrector.cc` for one zone. EnergyPlus runs it for every zone in
every predictor and corrector step:

- the convective internal gains of the zone's gain devices, with high temperature radiant heater
  and pool convection, and the return air gains when heat to return air goes to the zone;
- the non-system air flow sums (infiltration, ventilation, mixing, earth tube, cooling tower and
  the air balance outdoor air);
- as the corrector, the system air flow sums of a controlled zone, a return plenum (with an air
  terminal's upstream and downstream leaks) or a supply plenum, and parallel PIU backdraft
  leakage, divided by the zone multipliers.

The surface convection sums are unit 40 (`sumhat-rs`); here the zone's one space has no heat
transfer surfaces. `PsyCpAirFnW` comes from `psychrometrics-rs` (a path dependency).

The oracle (`rust/oracles/zonesums/`) sets up one zone of one space and calls the real function
for the zone. These return NaN in both (ADR-009): `which` outside 0 to 4, the zone kind outside 0
to 3, a flag outside 0 or 1, device or inlet counts outside 0 to 3, and multipliers outside 1 to
10000.

Not ported yet: space-level sums (space heat balance), AirflowNetwork multizone sums, and more
than one space, air terminal or PIU.

## Accepted gate exceptions (2026-11-23)

- **Size:** `rust-anything gate` fails only its size check: 344 lines of Rust (with tests) against
  a limit set by the 6-line C forwarder in `rust/oracles/zonesums/`. Waived under ADR-007.
- **Recording, diff and gate:** 13596 cases in all: 2600 zones, each asked for all five sums, plus
  rust-anything's generated cases. WSL kept going down and cutting long driver runs, so the cases
  were recorded and diffed in chunks of 1500 with the crate's own driver
  (`.rust-anything/driver_c.py record` and `diff`). All 13596/13596 match. The gate was run on a
  copy of this crate with the first 4000 cases: every check passes (behaviour 4000/4000) except
  size.
- **Speed:** 1.53x faster: 38 ns per call against 59 ns for the C++. Timed by a direct in-process
  loop over the recorded cases, both sides called through a C function pointer, best of 15
  interleaved runs.
