# localenv-rs

Rust port of `localenv.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `LocalEnvironment` (`localenv.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports four local environment functions from
`src/EnergyPlus/HeatBalanceSurfaceManager.cc` for one exterior surface. EnergyPlus runs them every
time step in models with local environments (`SurfaceProperty:LocalEnvironment` with ground or
surrounding surfaces):

- `GetGroundSurfacesTemperatureAverage`: the view-factor-weighted radiative average temperature of
  the surface's ground surfaces;
- `GetGroundSurfacesReflectanceAverage`: their view-factor-weighted average reflectance;
- `ReSetGroundSurfacesViewFactor`: the ground view factor sum reset from the surface's ground view
  factor;
- `GetSurroundingSurfacesTemperatureAverage`: the radiative average temperature of the surrounding
  surfaces.

The oracle (`rust/oracles/localenv/`) sets up one exterior surface with up to four ground surfaces
and four surrounding surfaces, their schedules as constant schedules, then calls the real
function. These return NaN in both (ADR-009): `which` outside 0 to 6, `op` outside 0 to 3, a flag
outside 0 or 1, and ground or surrounding surface counts outside 0 to 4.

Not ported yet: models with more than one surface (each surface is independent, so this is the
same code in a loop).

## Accepted gate exceptions (2026-11-23)

- **Size:** `rust-anything gate` fails only its size check: 292 lines of Rust (with tests) against
  a limit set by the 6-line C forwarder in `rust/oracles/localenv/`. Waived under ADR-007.
- **Recording, diff and gate:** 13167 cases in all: 1800 surfaces, each asked for all seven
  results, plus rust-anything's generated cases. WSL kept going down and cutting long driver runs,
  so the cases were recorded and diffed in chunks of 1500 with the crate's own driver
  (`.rust-anything/driver_c.py record` and `diff`). All 13167/13167 match. The gate was run on a
  copy of this crate with the first 4000 cases: every check passes (behaviour 4000/4000) except
  size.
- **Speed:** 0.86x, slower: 49 ns per call against 42 ns for the C++. The work is a few
  multiplications and two square roots, so both are dominated by passing 43 arguments and setting
  up the surface. Timed by a direct in-process loop over the recorded cases, both sides called
  through a C function pointer, best of 15 interleaved runs.
