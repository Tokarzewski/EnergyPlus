# airmixer-rs

Rust port of `airmixer.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `AirMixer` (`airmixer.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports `MixerComponent::CalcAirMixer` from `src/EnergyPlus/MixerComponent.cc`, which
EnergyPlus runs for every AirLoopHVAC:ZoneMixer (return paths, supply mixers of terminal units) on
every air loop simulation, many times per HVAC iteration:

- the outlet flow and maximum and minimum available flows summed over the inlets;
- with flow, each inlet's flow fraction and the humidity ratio, pressure and enthalpy mixed by
  mass flow, the outlet temperature from the enthalpy and humidity ratio (`psychrometrics-rs`,
  unit 1);
- with no flow, the same mixed by the flow fractions the last call left (a single inlet passing
  its temperature through);
- the maximum available flow kept at the outlet flow or more.

The oracle (`rust/oracles/airmixer/`) sets up one mixer as `InitAirMixer` leaves it, then calls the
real routine. These return NaN in both (ADR-009): any input that is not finite or lies outside what
EnergyPlus meets (see the shim).

Not ported yet: the parallel PIU leakage added at return mixers, `InitAirMixer` (with the flow
fraction reset at the start of an environment) and `UpdateAirMixer` (node copies, contaminants).

## Accepted gate exceptions (2026-11-23)

- **Size:** `rust-anything gate` fails only its size check: 184 lines of Rust (with tests) against
  a limit set by the 6-line C forwarder in `rust/oracles/airmixer/`. Waived under ADR-007.
- **Recording, diff and gate:** 13997 cases in all: 1227 mixers, each asked for all eleven results,
  plus rust-anything's generated cases. WSL kept going down and cutting long driver runs, so the
  cases were recorded and diffed in chunks of 1500 with the crate's own driver
  (`.rust-anything/driver_c.py record` and `diff`). All 13997/13997 match. The gate was run on a
  copy of this crate with the first 4000 cases: every check passes (behaviour 4000/4000) except
  size.
- **Speed:** slightly slower than the C++, 0.90x: 71 ns per call against 64 ns. The routine is a
  few sums, so the port's checks of all four inlets' 32 inputs weigh as much as the work. Timed by
  a direct in-process loop over the recorded cases, both sides called through a C function
  pointer, best of 15 interleaved runs.
