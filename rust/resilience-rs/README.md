# resilience-rs

Rust port of `resilience.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `ThermalResilience` (`resilience.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports `HeatBalanceSurfaceManager::CalcThermalResilience` from
`src/EnergyPlus/HeatBalanceSurfaceManager.cc` for one zone. EnergyPlus runs it for every zone on
every zone time step when the heat index or humidex is reported or the thermal resilience summary
is on:

- the heat index from the zone air temperature and relative humidity averaged over the zone time
  step, by the simplified method (the NWS regression in Fahrenheit, with its dry and humid
  adjustments) or the extended method (`heatindex-rs`, a path dependency);
- the humidex from the dew point.

The psychrometric functions come from `psychrometrics-rs` (a path dependency).

The oracle (`rust/oracles/resilience/`) sets up one zone, with the thermal resilience summary on
and past the first call, then calls the real function. These return NaN in both (ADR-009):
`which` and the method outside 0 or 1, and barometric pressures outside 10000 to 200000 Pa.

Not ported yet: setting up the output variables on the first call.

## Accepted gate exceptions (2026-11-23)

- **Size:** `rust-anything gate` fails only its size check: 85 lines of Rust against a limit set
  by the 6-line C forwarder in `rust/oracles/resilience/`. Waived under ADR-007.
- **Recording, diff and gate:** 12642 cases in all: 3100 zone air states, each asked for both
  results under both methods, plus rust-anything's generated cases. WSL kept going down and
  cutting long driver runs, so the cases were recorded and diffed in chunks of 1500 with the
  crate's own driver (`.rust-anything/driver_c.py record` and `diff`). All 12642/12642 match. The
  gate was run on a copy of this crate with the first 4000 cases (its path dependencies made
  absolute): every check passes (behaviour 4000/4000) except size.
- **Speed:** 2.39x faster: 1.9 us per call against 4.5 us for the C++, both dominated by the
  extended heat index's root solving. It ran at 2.07x until `psychrometrics-rs` kept the same
  saturation temperature cache as the C++ (2026-11-23). Timed by a direct in-process loop over
  the recorded cases, both sides called through a C function pointer, best of 15 interleaved runs.
