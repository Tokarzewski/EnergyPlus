# vectors-rs

Rust port of `vectors.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `VAreaPolygon` (`vectors.c:15`)
- `VNewellArea` (`vectors.c:20`)
- `VNewellNormal` (`vectors.c:25`)
- `VAzimuthTilt` (`vectors.c:30`)
- `VCoPlanar` (`vectors.c:35`)
- `VPointsInPlane` (`vectors.c:40`)
- `VRound` (`vectors.c:45`)
- `VNormalize` (`vectors.c:50`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports `src/EnergyPlus/Vectors.cc`: `AreaPolygon`, `VecSquaredLength`, `VecLength`,
`VecNormalize`, `VecRound`, `DetermineAzimuthAndTilt`, `CreateNewellAreaVector`,
`CreateNewellSurfaceNormalVector`, `CalcCoPlanarNess` and `PointsInPlane`, with the `Vector3D`
operations and `Plane::fromVertices` / `signedDistance` from `Geometry/` in the same operation
order. Not ported: `CalcPolyhedronVolume` (it takes a `Polyhedron` and the module's state),
`VecNegate` and `CompareTwoVectors` (one line each; no caller needs them through the oracle).

The oracle (`rust/oracles/vectors/`) takes a polygon as the first n of five vertices (n from 3 to
5) and returns one of a function's several results by `which`. Outside 3 to 5 vertices, and where
`VecRound`'s `nint64` would cast a value that does not fit an int64, both return NaN (ADR-009).

## Accepted gate exceptions (2026-11-22)

- **Size:** `rust-anything gate` fails only its size check: about 330 lines in `src/port.rs`
  against a limit set by the 41-line C forwarder in `rust/oracles/vectors/`. Waived under ADR-007.
- **Speed:** `DetermineAzimuthAndTilt` ties with the C++ (1.03x; its time is in `atan2` and
  `acos`); the others are 1.1x to 2.1x faster.
