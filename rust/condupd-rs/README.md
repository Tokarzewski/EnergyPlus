# condupd-rs

Rust port of `condupd.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `CondUpd` (`condupd.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports two routines from `src/EnergyPlus/PlantUtilities.cc` that every water-cooled
chiller, heat pump and heat recovery chiller calls at every plant iteration to hand its condenser or
heat recovery side back to the plant:

- `UpdateChillerComponentCondenserSide` and `UpdateComponentHeatRecoverySide`: when the model's flow
  or temperatures differ from the nodes' (or the inlet has no flow but heat moves), or on the first
  HVAC iteration, the outlet temperature is the inlet's plus the heat over the flow times the water
  specific heat, and the loop side and every connected loop it puts demand on are flagged to be
  simulated again; otherwise the side's flag is cleared;
- the condenser side checks the heat's magnitude for the no-flow case, the heat recovery side only
  positive heat;
- the water specific heat comes from `fluidproperties-rs` (unit 13), cached by temperature as the
  C++ caches it.

The oracle (`rust/oracles/condupd/`) calls the real routines on a water loop with up to two
connected loops and returns one result at a time. These return NaN in both (ADR-009): any input
that is not finite or lies outside what EnergyPlus meets (see the shim).

## Gate (2026-11-23)

- **Gate:** `rust-anything gate` passes every check but size (158 lines of Rust against the 6-line
  C forwarder, which hides the two C++ routines). Waived under ADR-007.
- **Recording, diff and gate:** 13826 cases in all: 13500 real ones (3374 calls asked for all four
  results, plus 4) and rust-anything's generated cases, recorded and diffed in chunks with the
  crate's own driver, from fresh chunk folders. All 13826/13826 match. The gate was run on a copy
  of this crate with the first 4000 cases: behaviour 4000/4000.
- **Speed:** 1.32x (C++ 44 ns per call, Rust 33 ns). Timed by a direct in-process loop over the
  recorded cases, both sides called through a C function pointer, best of 15 interleaved runs.
