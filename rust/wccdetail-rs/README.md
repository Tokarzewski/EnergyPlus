# wccdetail-rs

Rust port of `wccdetail.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `WaterCoolDetail` (`wccdetail.c:8`)

## Loop

```sh
rust-anything record .   # record what the C++ does
rust-anything build .    # build the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports `CoolingCoil` from `src/EnergyPlus/WaterCoils.cc` with the detailed analysis
(Coil:Cooling:Water with `DetailedAnalysis` as its type of analysis), reusing `watercc-rs`'s (unit 88) `CoilCompletelyDry`
and `CoilCompletelyWet`:

- a dry coil when the entering air's dew point is at or below the water temperature;
- a completely wet coil when the wet coil's surface at the air inlet is at or below the dew point;
- otherwise `CoilPartWetPartDry`: on the first HVAC iteration the wet fraction starts from the dew
  point, otherwise from the saved one; `General::Iterate` finds the water temperature at the
  wet/dry boundary inside `CoilAreaFracIter`'s perturbation, linear or quadratic iteration on the
  wet fraction, and the fraction is saved for the next call.

The oracle (`rust/oracles/wccdetail/`) calls the real routine on one coil and returns one result at
a time (see the shim); out-of-range inputs return NaN in both (ADR-009).

The water specific heat now goes through a copy of `GlycolProps::getSpecificHeat`'s cache
(`EP_cache_GlycolSpecificHeat`), empty at the start of each call as in the oracle's freshly forked
process: a slot keyed by the top 36 bits of `T + 1000` keeps the specific heat of the first exact
temperature that filled it. The boundary iterations ask for nearby temperatures that share a slot,
and the C++ then returns the first one's value. `watercc-rs` used to keep only the last temperature;
with the real cache 707 of the first 4000 cases went from a last-digit difference to an exact
match. `watercc-rs` still matches all 13855 of its cases.

## Gate (2026-11-24)

- **Gate:** `rust-anything gate` passes every check but size (397 lines of Rust for the 6-line C
  forwarder, which hides `CoolingCoil`, `CoilPartWetPartDry`, `CoilAreaFracIter` and
  `General::Iterate`). Waived under ADR-007. Run on a copy of this crate with the first 4000 cases:
  behaviour 4000/4000.
- **Diff:** 13871 cases (13500 real ones and rust-anything's generated cases): 13871/13871 match.
- **Speed:** 0.93x (4666 ns per call against 4351 ns), `rust-anything bench` on the 4000-case copy,
  the crossing included.
