# tarcoggas-rs

Rust port of `tarcoggas.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `Gasses90` (`tarcoggas.c:10`)
- `GassesLow` (`tarcoggas.c:15`)
- `TarcogSolve` (`tarcoggas.c:20`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports TARCOG's gas property and solver routines: `GASSES90` (single gases and
ISO 15099 and EN 673 mixtures, with its zero-fraction error 2011) and `GassesLow` (low-pressure
conduction, with its gamma error 40) from `src/EnergyPlus/TARCOGGasses90.cc`, and
`EquationsSolver` with `ludcmp` (and its singular-matrix error 13) and `lubksb` from
`src/EnergyPlus/TARCOGCommon.cc`. The rest of TARCOG (the layer heat balance in `TARCOGMain.cc`,
deflection, arguments and output) is not ported yet.

The oracle (`rust/oracles/tarcoggas/`) holds the ISO 15099 coefficients of air, argon, krypton
and xenon and builds linear systems from four parameters. Where a NaN or infinite matrix leaves a
pivot index at 0, the C++ reads outside its arrays (ObjexxFCL aborts; the case is recorded as a
crash); the port returns NaN there.

## Accepted gate exceptions (2026-11-22)

- **Size:** `rust-anything gate` fails only its size check: about 360 lines in `src/port.rs`
  against a limit set by the 16-line C forwarder in `rust/oracles/tarcoggas/`. Waived under ADR-007.
- **Speed:** `EquationsSolver` ties with the C++ (0.99x); the gas routines are 2.4x to 3.1x faster.
