# oamixer-rs

Rust port of `oamixer.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `OAMixer` (`oamixer.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports `MixedAir::OAMixerProps::CalcOAMixer` from `src/EnergyPlus/MixedAir.cc`, which
EnergyPlus runs for every OutdoorAir:Mixer on every air loop simulation, many times per HVAC
iteration:

- the return air split into relief and recirculated air (none below zero, the relief flow then
  cut to the return flow);
- the mixed air's mass flow, enthalpy, humidity ratio and pressure by mass flow, its temperature
  from the enthalpy and humidity ratio, moved to the saturation temperature at constant enthalpy
  when it lies below it (`psychrometrics-rs`, unit 1), with a one entry cache of the saturation
  temperature by exact inputs like the C++'s state cache.

The oracle (`rust/oracles/oamixer/`) sets up one mixer as `InitOAMixer` leaves it, then calls the
real routine. These return NaN in both (ADR-009): any input that is not finite or lies outside what
EnergyPlus meets (see the shim).

Not ported yet: `InitOAMixer` and `UpdateOAMixer` (node copies, contaminants), and the outdoor air
controller that sets the flows.

## Accepted gate exceptions (2026-11-23)

- **Size:** `rust-anything gate` fails only its size check: 139 lines of Rust (with tests) against
  a limit set by the 6-line C forwarder in `rust/oracles/oamixer/`. Waived under ADR-007.
- **Recording, diff and gate:** 13805 cases in all: 2250 mixers, each asked for all six results,
  plus rust-anything's generated cases. WSL kept going down and cutting long driver runs, so the
  cases were recorded and diffed in chunks of 1500 with the crate's own driver
  (`.rust-anything/driver_c.py record` and `diff`). All 13805/13805 match. The gate was run on a
  copy of this crate with the first 4000 cases: every check passes (behaviour 4000/4000) except
  size.
- **Speed:** slightly slower than the C++, 0.91x: 38 ns per call against 34 ns. Without the
  saturation temperature cache the port was 0.54x, as the C++ keeps its cache in the EnergyPlus
  state; what remains is the routine's small size against the per-call overhead. Timed by a direct
  in-process loop over the recorded cases, both sides called through a C function pointer, best of
  15 interleaved runs.
