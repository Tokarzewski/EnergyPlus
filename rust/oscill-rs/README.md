# oscill-rs

Rust port of `oscill.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `Oscillate` (`oscill.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports `ZoneTempPredictorCorrector::DetectOscillatingZoneTemp` from
`src/EnergyPlus/ZoneTempPredictorCorrector.cc` for up to three zones, once its output variables
are set up and reported. EnergyPlus runs it at every system time step:

- each zone's air temperature history shift;
- the test for three swings of more than `HVAC::OscillateMagnitude` (0.15 C) in alternating
  directions;
- the oscillation time, and the time during occupancy (from the ASH55 comfort results) and in
  the dead band or set back;
- the facility values for any zone and their run period sums.

The oracle (`rust/oracles/oscill/`) sets up the zones with the output variables already set up,
then calls the real `DetectOscillatingZoneTemp`. These return NaN in both (ADR-009): `which`
outside 0 to 26 or naming a zone past `nzones`, `nzones` outside 1 to 3, and a flag outside 0 or
1.

Not ported: the first call's output variable set-up, and the case where no oscillation variable
is reported (the function then does nothing).

## Accepted gate exceptions (2026-11-23)

- **Size:** `rust-anything gate` fails only its size check: 221 lines of Rust (with tests) against
  a limit set by the 6-line C forwarder in `rust/oracles/oscill/`. Waived under ADR-007.
- **Recording, diff and gate:** 14179 cases in all: 510 sets of zones, each asked for all 27
  results, plus rust-anything's generated cases. WSL kept going down and cutting long driver
  runs, so the cases were recorded and diffed in chunks of 1500 with the crate's own driver
  (`.rust-anything/driver_c.py record` and `diff`). All 14179/14179 match. The gate was run on a
  copy of this crate with the first 4000 cases: every check passes (behaviour 4000/4000) except
  size.
- **Speed:** 1.24x faster: 32 ns per call against 40 ns for the C++, whose call also sets the
  zones up. Timed by a direct in-process loop over the recorded cases, both sides called through
  a C function pointer, best of 15 interleaved runs.
