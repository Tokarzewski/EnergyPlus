# polyclip-rs

Rust port of `polyclip.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `PolyOverlap` (`polyclip.c:8`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports the polygon overlap of `src/EnergyPlus/SolarShading.cc`: `HTRANS1` and
`HTRANS0` (homogeneous coordinates of a figure's vertices and sides, and its area), `CLIPPOLY`
(Sutherland-Hodgman clipping on 0.01 mm integer coordinates, with its near-duplicate removal on
the last edge and the intersection guard sized for 4-vertex surfaces) and
`DeterminePolygonOverlap` (the overlap figure, its status, signed area and transmittance).

The oracle (`rust/oracles/polyclip/`) loads two polygons of 3 or 4 vertices into figures 1 and 2,
overlaps figure 2 on figure 1 into figure 3, and sizes and zeroes the figure and scratch arrays on
every call. Vertex counts other than 3 or 4 and coordinates that are not finite or lie past
1000 m (whose homogeneous products would overflow `Int64`) return NaN in both (ADR-009). The
inputs are convex or degenerate shadow-like pairs; with self-intersecting polygons the C++ can
write past its scratch arrays, which the port grows instead.

## Accepted gate exceptions (2026-11-22)

- **Size:** `rust-anything gate` fails only its size check: about 350 lines in `src/port.rs`
  against a limit set by the 6-line C forwarder in `rust/oracles/polyclip/`. Waived under ADR-007.
- **Speed:** 0.89x, so slower: 730 ns per call against 651 ns for the C++ (both include the
  oracle's setup; the shim sizes and zeroes the figure arrays on every call). The port allocates
  its scratch vectors per call; fixed-size arrays are the first thing to try. Another session
  was building in the same WSL, so the timings may carry some noise.
