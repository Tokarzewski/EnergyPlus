# updtemp-rs

Rust port of `updtemp.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `UpdateTemperatures` (`updtemp.c:9`)
- `DownInterpolate5` (`updtemp.c:14`)

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## What is ported

`src/port.rs` ports from `src/EnergyPlus/ZoneTempPredictorCorrector.cc`:

- `ZoneSpaceHeatBalanceData::updateTemperatures` for one fully mixed zone (no space), which
  `predictSystemLoad` runs for every zone at every system time step: when the system time step
  shortens, the system node and thermostat air go back to the zone time step history, and when
  the system time step count changed, the air temperature and humidity ratio histories are
  down-interpolated; then the history the balance equations use is picked;
- both variants of `DownInterpolate4HistoryValues`: the four-value one those histories use, and
  the five-value one the contaminant predictor uses (`DownInterpolate5`).

`PsyHFnTdbW` comes from `psychrometrics-rs` (a path dependency).

The oracle (`rust/oracles/updtemp/`) sets up one zone, then calls the real `updateTemperatures`
and `DownInterpolate4HistoryValues`. These return NaN in both (ADR-009): `which` out of range and
a flag outside 0 or 1.

Not ported yet: spaces, and the down-interpolation of the room air model (displacement
ventilation, underfloor and airflow network) histories.

## Accepted gate exceptions (2026-11-23)

- **Size:** `rust-anything gate` fails only its size check: 234 lines of Rust (with tests) against
  a limit set by the 11-line C forwarder in `rust/oracles/updtemp/`. Waived under ADR-007.
- **Recording, diff and gate:** 14494 cases in all: 560 zones, each asked for all 22 results, and
  300 contaminant histories, each asked for all five values, plus rust-anything's generated cases.
  WSL kept going down and cutting long driver runs, so the cases were recorded and diffed in
  chunks of 1500 with the crate's own driver (`.rust-anything/driver_c.py record` and `diff`). All
  14494/14494 match. The gate was run on a copy of this crate with the first 4000 cases: every
  check passes (behaviour 4000/4000) except size.
- **Speed:** `UpdateTemperatures` is 1.53x faster: 16 ns per call against 24 ns for the C++, whose
  call also sets the zone up. `DownInterpolate5` is level at 5 ns per call (1.06x). Timed by a
  direct in-process loop over the recorded cases, both sides called through a C function
  pointer, best of 15 interleaved runs.
